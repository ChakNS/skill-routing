# Platform Output Prep

This router prepares manual handoff packages. It does not publish.

## General Social

Include:

- Final post text.
- Optional title or hook variants.
- Asset list.
- Suggested tags when evidence supports them.
- Manual publish checklist.

## Xiaohongshu / Rednote

Include:

- Title variants.
- Cover/card direction or rendered asset path if created.
- Body copy with paragraph breaks.
- Topic tags only when provided or evidence-backed.
- Manual checklist: upload images, paste copy, add tags, preview first screen, publish manually.

## LinkedIn

Include:

- Final post.
- Optional first-line variants.
- Suggested media attachment notes.
- Manual checklist: paste, check line breaks, attach asset, preview, publish manually.

## YouTube / Thumbnail

Include:

- Thumbnail concept or asset path.
- Title variants.
- Description draft when requested.
- Manual checklist: upload asset, verify crop, preview mobile/desktop, publish manually.

## Newsletter

Include:

- Subject line variants.
- Preview text.
- Body draft.
- Source list if research was used.
- Manual checklist: paste into email tool, preview, test-send, schedule manually.
